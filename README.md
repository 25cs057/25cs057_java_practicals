## Directory Structure Standards

Each practical branch contains its own independent directory matching this specification:
```
Practical-XX/
    Source_Code/
        [all required Java source files]
    Screenshots/
        [actual execution screenshots]
    25CS057_KrupalParmar_PracticalXX.docx
    README.md
```

Each generated `.docx` report includes:
- Unabridged official problem statements
- Complete, tested Java source codes (Consolas monospace formatting)
- Live terminal execution screenshots
- Clickable practical-specific GitHub repository footer link
